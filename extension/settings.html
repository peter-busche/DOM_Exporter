Files go into this subfolder of the save location; it is created if missing. Use / for nested folders, such as homepage/nav. Change it per task to keep exports grouped. You can also edit it in the extension popup.

How folder access works

Chrome asks you to approve access to the folder you choose. That approval can lapse, for example after Chrome restarts. When it has lapsed, exports are saved to your Downloads folder instead and the extension tells you; come back here and click Re-allow access. If Chrome offers Allow on every visit, choosing it should stop the approval from lapsing.

Chrome does not let any site or extension pick a few protected locations, such as your home folder itself. Pick a project folder or a subfolder instead.
